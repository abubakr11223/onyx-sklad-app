## 1. Две задачи этого ТЗ

1. **Шоу-рум: выбор камня из любой партии**, а не только из уже выделенных плит (сейчас в списке всего одна плита).
2. **Фото при приёмке партии** — складчик прикладывает общее фото партии, помимо фото узоров.

---

## ЧАСТЬ A · Шоу-рум: выделение плиты из партии

### 2. Проблема (диагностика вживую)

В разделе «Шоу-рум» в выпадающем списке для отправки — **только одна плита** («Плита №1 — Травертин»). Все остальные камни не выбрать.

**Причина (архитектурная, не баг сам по себе):** по основному ТЗ (раздел 4.1) камень учитывается **партиями**, а отдельная плита «выделяется» из партии только когда понадобилась (фотозапрос под клиента и т.п.). Шоу-рум сейчас показывает только **уже выделенные** плиты — а такая пока одна. Весь остальной камень живёт внутри партий как количество, поштучно его в списке нет.

**Почему это мешает:** в шоу-рум выставляют образец камня со склада. Менеджер/складчик должен взять плиту из **любой** партии, а не только из редких заранее выделенных. Сейчас — тупик: партий много, а в шоу-рум отправить почти нечего.

### 3. Решение · Механизм «выделить плиту из партии»

Нужен общий механизм: взять одну (или несколько) плит из партии и сделать их отдельными единицами. Это тот же механизм, что нужен и для «Разбить → Плита», и для фотозапросов B2C — **сделать один раз и переиспользовать везде** (не писать отдельно под шоу-рум).

**Как работает выделение:**
- Выбираем вид камня / партию → указываем «взять N плит» → система создаёт из партии N поимённых плит (Плита №…), уменьшая остаток партии на это количество.
- Учёт сходится: партия минус N плит = N новых отдельных плит. Ничего не теряется и не задваивается.

### 4. Как это применить в шоу-руме

Форму «Отправить в шоу-рум» переделать так, чтобы источником была **партия**, а не только список выделенных плит:

```
ОТПРАВИТЬ В ШОУ-РУМ
Источник:
  ( ) Из партии        → выбрать вид/партию → сколько плит (обычно 1)
  ( ) Готовая плита     → выбрать из уже выделенных (как сейчас)
  ( ) Бой / остаток     → выбрать конкретный кусок

Стенд / комментарий: [ ... ]
[ Отправить в шоу-рум ]
```

- «Из партии» — основной путь: выбрал партию, взял 1 плиту → она выделяется из партии и уходит на витрину со статусом «в шоу-руме», остаток партии уменьшается.
- «Готовая плита» — если плита уже выделена (текущее поведение, оставить).
- «Бой / остаток» — можно выставить и обрезок как образец.

### 5. Что проверить (часть A)

1. В шоу-руме можно выбрать камень из любой партии, а не только из одной выделенной плиты.
2. При отправке «из партии» создаётся отдельная плита, остаток партии уменьшается на неё.
3. Учёт сходится: партия − N = N плит; сумма не теряется.
4. Плита в шоу-руме имеет статус «в шоу-руме», в обычном наличии не продаётся.
5. Возврат из шоу-рума на склад возвращает плиту (или, по возможности, «вливает» обратно в партию).
6. Тот же механизм выделения работает и в «Разбить → Плита» (там была та же пустота).

## ЧАСТЬ B · Фото партии при приёмке

### 6. Что есть сейчас (диагностика)

В приёмке фото есть **только в узорах** (подгруппы: «Фото узора»). На **уровне партии общего фото нет** — блоки «Количество», «Локации», «Детали», но фото самой партии отсутствует.

### 7. Что добавить

В форму приёмки добавить **фото партии** — общий снимок(и) поступившего камня, независимо от узоров:
- Поле «Фото партии» (одно или несколько фото) — в блоке «Детали» или сразу после «Количество».
- Необязательное, но желательное: складчик фотографирует камень при приёмке (как пришёл, на паллете / в контейнере).
- Фиксируется дата съёмки (как у фото узоров и фотозапросов).

**Зачем:**
- Видно, как камень реально выглядит и в каком состоянии пришёл (споры с поставщиком, брак при поставке).
- Для однородной партии без узоров сейчас фото вообще нет — камень «слепой». Общее фото партии это закрывает.
- Менеджер/владелец видят партию визуально, не выходя на склад.

**Соотношение с фото узоров:**
- Фото узора (в подгруппах) — остаётся, это фото конкретного рисунка для B2C.
- Фото партии — общий снимок всей поставки. Одно другое не заменяет: партия — общий вид, узор — конкретный рисунок.

### 8. Что проверить (часть B)

1. В приёмке есть поле «Фото партии» (помимо фото узоров).
2. Можно приложить 1+ фото; сохраняется с датой.
3. Фото партии видно в карточке партии (поиск, продажа, редактирование партии).
4. Однородная партия (без узоров) может иметь фото — камень больше не «слепой».
5. Фото партии и фото узоров не конфликтуют, показываются раздельно.

## 9. Приоритет и порядок

**Часть A (шоу-рум из партии) — High.** Сейчас шоу-рум почти нерабочий (одна плита). Механизм выделения плиты — базовый, пригодится и в «Разбить», и в фотозапросах.

**Часть B (фото партии) — Medium.** Полезно, несложно, улучшает учёт.

**Порядок:**
1. Часть A: механизм «выделить плиту из партии» + применение в шоу-руме (и заодно в «Разбить → Плита»).
2. Часть B: фото партии в приёмке.

**Связь:** механизм выделения плиты — общий, переиспользовать в «Разбить», шоу-руме, фотозапросах. Размеры уже в см (ТЗ №12 внедрено). Редактирование партии (ТЗ №14) уже есть — фото партии должно быть доступно и в редактировании.
