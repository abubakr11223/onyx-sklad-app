# Обучающие видео по ролям (ТЗ №21, часть Б)

**Статус: три видео собраны** (голос ElevenLabs «Mirjalol», титры на узбекском).
На сайт не выкладываются и ссылки в меню нет — по решению владельца видео
раздаются сотрудникам отдельно (Telegram). Готовые файлы — `video/remotion/out/`.

## Что будет

| Файл | Роль | Длительность | Формат |
| --- | --- | --- | --- |
| `onyx-vladelets.mp4` | Владелец | 3:38, 20 МБ | 1920×1080, компьютер (сайт 1440 px) |
| `onyx-menedzher.mp4` | Менеджер | 3:30, 22 МБ | 1920×1080, компьютер (сайт 1440 px) |
| `onyx-zavsklad.mp4` | Зав. складом (его же видит складчик) | 3:26, 19 МБ | 1080×1920, телефон (сайт 390 px) |

Сценарии: [onyx-vladelets.md](onyx-vladelets.md), [onyx-menedzher.md](onyx-menedzher.md),
[onyx-zavsklad.md](onyx-zavsklad.md). Все титры и текст диктора — в
[texts.uz.json](texts.uz.json) (ключи: роль → сцена → шаг), чтобы собрать
версию на другом языке без пересъёмки.

## Пересборка

1. `npm run video:db` — демо-база `onyx_video` (не боевая): камни с фото,
   клиенты «Demo mijoz …», заполненная карта.
2. `npm run video:serve` + `npm run video:capture -- <роль>` — Playwright проходит
   сценарий и снимает скриншоты с координатами нажатий в `video/captures/<роль>/`.
3. Голос: `video/remotion/public/audio/<роль>/<сцена>-<шаг>.mp3` (+ `intro`,
   `outro`) — текст диктора из `texts.uz.json`, синтез ElevenLabs.
4. `npm run video:build -- <vladelets|menedzher|zavsklad>` — Remotion собирает
   MP4 в `video/remotion/out/` (зависимости: `cd video/remotion && npm i`).

Шаги с Telegram-ботом (зав. склад 4-5, 5-1, 5-2) на стенде не снять: чат
рисует `video/telegram-mock.ts` (`npm run video:telegram`, capture zavsklad
вызывает его сам) — тексты бота взяты из кода бота; поменялись там — поменять и тут.

## Данные в кадре (ТЗ №21 §3.2 п.3)

- Отдельный стенд или preview-сборка со своей базой — не боевая база.
- 3–4 вида камня с фото (например «Оникс Медовый», «Травертин Классик»).
- 2–3 клиента с пометкой «демо» («Demo mijoz 1» …), заполненные блоки карты.
- Без записей «ТЕСТ», без реальных телефонов, почт и Telegram ID.

## Требования к файлу (ТЗ №21 §3.3)

- MP4 (H.264), 30 кадров/с, до 50 МБ (отправка в Telegram).
- Язык — узбекский (латиница); названия разделов и кнопок — как на экране, по-русски.
- Титр на каждом шаге; видео понятно без звука. Голос — синтез речи по тексту
  сценария (если на пилоте звучит плохо — только титры, решает РП).
- Нажимаемый элемент — рамка honey 2 px; курсор или касание видны. Без музыки,
  заставки не длиннее 3 с.
- В начале заставка: Onyx, роль, список сцен. Каждая сцена начинается с плашки
  названия; тайм-коды сцен прикладываются текстом.
- Каждая операция — целиком: от открытия раздела до сообщения об успехе.

## Порядок

1. РП согласует три сценария.
2. Демо-данные на отдельном стенде.
3. Пилот — видео владельца → РП принимает стиль.
4. Видео менеджера и зав. складом. ✅ Ссылку «Видеоинструкция» в меню владелец отменил — видео раздаются отдельно.
